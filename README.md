## 📂 Featured Projects

- **[Borrow My Charger](https://github.com/yusrax/borrow-my-charger)**  
  Full-stack web application connecting EV drivers with homeowners offering private charging points.  
  Built with vanilla PHP, JavaScript, HTML, and CSS, featuring user authentication, interactive maps, and booking functionality.  
  Focused on designing a practical user flow for discovering, booking, and managing charger access.

- **[Flow](https://github.com/yusrax/flow)**  
  Cross-platform mobile application built with React Native and Firebase to support students with ADHD in managing academic tasks.  
  Implemented user authentication, real-time data handling, and notifications, using React Navigation, Context, Redux, and hooks.  
  Designed with a strong focus on usability, accessibility, and reducing cognitive load through intuitive workflows.

- **[BookShelf](https://github.com/yusrax/book-review-frontend)**  
  Full-stack book review platform with a React frontend and Symfony API backend.  
  Built reusable components, managed application state, and integrated REST APIs for authentication, reviews, and data management.  
  Focused on user journeys and seamless interaction flows for browsing, reviewing, and managing content.

- **[World Trade Simulation](https://github.com/yusrax/world-trade-simulation)**  
  C++ OpenGL application visualising global trade networks using a Pajek dataset.  
  Implemented custom physics-based calculations (e.g. kinetic energy, force dynamics) and interactive visual elements.  
  Focused on building accurate simulations and real-time visual feedback through mathematical modelling.

- **[Bruntwood SciTech Visualiser](https://github.com/bonewellj/Bruntwood)**  
  Hackathon project creating a data visualisation tool to analyse meeting room usage.  
  Built using PHP and JPGraph to present complex data in a clear, actionable format for decision-making.
